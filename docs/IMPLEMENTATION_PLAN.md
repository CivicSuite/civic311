# Civic311 Implementation Plan

Civic311 v0.1.1 preserves the deterministic foundation and aligns it to `civiccore==0.3.0`: runtime shell, sample service request intake, triage suggestion helper, duplicate-candidate review, department routing helper, Open311-compatible export checklist, and public sample UI.

Later releases add configured service catalogs, resident authentication handoffs, CivicAccess/CivicCode context links, official 311/work-order integrations, SLA/response-time policy packs, and production data governance.

The v0.1.1 boundary is deliberate: no official dispatch, no emergency response, no work-order creation, no legal advice, no live LLM calls, and no system-of-record write-back.
