# Civic311 Milestones

## Milestone 0 - Repository foundation

Documentation, governance files, CI, release gates, and CivicCore pin.

## Milestone 1 - Runtime shell

FastAPI app, root/health endpoints, package version, and public sample UI route.

## Milestone 2 - Request intake

Deterministic resident service request intake stub with staff-review boundary.

## Milestone 3 - Triage suggestions

Deterministic triage helper with department hints and no dispatch authority.

## Milestone 4 - Duplicate-candidate review

Duplicate-candidate helper that surfaces possible matches without merging, closing, or suppressing requests.

## Milestone 5 - Department routing

Routing checklist with resident-update requirement and system-of-record boundary.

## Milestone 6 - Open311 export

Open311-compatible export checklist with records and handoff notes.

## Milestone 7 - Release

Accessible public sample page at `/civic311`, release artifacts, CI green, and umbrella compatibility update.
